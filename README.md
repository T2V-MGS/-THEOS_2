# THEOS-2 Dashboard — แชร์ข้อมูลเรียลไทม์

เมื่อ "ผู้แก้ไข" อัปโหลดหรือลบไฟล์ GeoJSON เพื่อน ๆ ที่เปิดหน้าเว็บอยู่จะเห็นกราฟ/แผนที่/ตัวเลขเปลี่ยนทันที โดยไม่ต้องกดรีเฟรช

## 1) หลักการทำงาน

```
ผู้แก้ไข ──อัปโหลด GeoJSON──▶  server.js  ──เก็บไฟล์──▶ storage/
                                  │
                                  └─ SSE (/api/events) แจ้ง "มีการเปลี่ยนแปลง"
                                        │
         เพื่อนทุกคน ◀─ live.js ดึงรายการใหม่ → parse() → mk() → setData() (โค้ดเดิมของคุณ)
```

- **ไม่แก้โค้ด Dashboard เดิม** — เพิ่มเพียง `<script src="live.js">` ท้าย index.html
- **ผู้แก้ไข** = ใส่ `EDIT_KEY` (ปุ่ม 🔑 มุมล่างของหน้า) → อัปโหลด/ลบแล้วทุกเครื่องเห็น
- **ผู้ชม** = ไม่ต้องใส่รหัส ดูได้อย่างเดียว (ยังเพิ่มไฟล์ดูส่วนตัวในเครื่องตัวเองได้เหมือนเดิม)
- ใช้ SSE แทน WebSocket เพราะง่ายกว่า ผ่านพร็อกซี/โฮสต์ฟรีได้ดี และต่อใหม่เองเมื่อหลุด

## 2) โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `server.js` | เซิร์ฟเวอร์ Express: API อัปโหลด/ลบ/ดึงไฟล์ + SSE + เสิร์ฟหน้าเว็บ |
| `public/index.html` | Dashboard เดิมของคุณ (เพิ่ม 1 บรรทัดเรียก live.js) |
| `public/live.js` | ฝั่งเบราว์เซอร์: ซิงก์ไฟล์, แถบสถานะ Live, โหมดแก้ไข |
| `public/data/` | **วาง CUF2024.js, CUF2025.js, CUF2026.js เดิมที่นี่** |
| `storage/` | ไฟล์ที่อัปโหลดผ่านหน้าเว็บ (สร้างอัตโนมัติ) |
| `.env.example` | ตัวอย่างค่าตั้ง (EDIT_KEY ฯลฯ) |
| `Dockerfile` | สำหรับ Railway / Fly.io / VPS แบบ Docker |

## 3) ทดลองในเครื่อง (ต้องมี Node.js 18+ จาก nodejs.org)

```bash
cd theos-live
npm install
# Windows PowerShell:  $env:EDIT_KEY="รหัสของคุณ"; npm start
# Mac/Linux:           EDIT_KEY="รหัสของคุณ" npm start
```
เปิด http://localhost:3000 → กด 🔑 ใส่รหัส → เลือกไฟล์ GeoJSON ที่มุมขวาบน
ทดสอบเรียลไทม์: เปิดอีกแท็บ/โหมดไม่ระบุตัวตน (ไม่ใส่รหัส) แล้วอัปโหลดจากแท็บแรก

## 4) แชร์ให้เพื่อน — เลือก 1 ทาง

### ทาง A: เร็วสุด ไม่ต้องจ่ายเงิน (เปิดเครื่องตัวเองทิ้งไว้)
```bash
# ติดตั้ง cloudflared แล้วรันขนานกับ npm start
cloudflared tunnel --url http://localhost:3000
```
ได้ลิงก์ `https://xxxx.trycloudflare.com` ส่งให้เพื่อนได้ทันที (ลิงก์เปลี่ยนทุกครั้งที่รันใหม่, เครื่องต้องเปิดอยู่)

### ทาง B: โฮสต์ออนไลน์ถาวร
**Render.com**: อัปโหลดโปรเจกต์ขึ้น GitHub → New Web Service → Build `npm install` / Start `npm start`
→ Environment: `EDIT_KEY=...`, `DATA_DIR=/var/data` → เพิ่ม **Disk** mount ที่ `/var/data`
⚠ แพ็กเกจฟรีไม่มี Disk ถาวรและหลับเมื่อไม่มีคนใช้ — ไฟล์ที่อัปโหลดจะหายเมื่อรีสตาร์ต ควรใช้แพ็กเกจที่มี Disk (ตรวจราคาล่าสุดในเว็บ Render)

**Railway / Fly.io**: ใช้ Dockerfile ที่ให้ไว้ → สร้าง **Volume** mount ที่ `/data` → ตั้ง `EDIT_KEY`

**VPS (Ubuntu)**: ติดตั้ง Node 20 → `npm install --omit=dev` → รันด้วย `pm2 start server.js` → ใช้ Caddy ทำ HTTPS:
```
yourdomain.com {
    reverse_proxy localhost:3000
}
```
(ถ้าใช้ Nginx ต้องใส่ `proxy_buffering off;` ให้ /api/events ไม่งั้น SSE จะค้าง)

## 5) วิธีใช้งานประจำวัน
1. เข้าเว็บ → กด 🔑 ใส่ EDIT_KEY (จำไว้ในเบราว์เซอร์)
2. เลือกไฟล์ GeoJSON (เพิ่มได้หลายไฟล์) → ทุกคนเห็นพร้อมกัน แถบด้านล่างขึ้นข้อความ "เพิ่ม ชื่อไฟล์"
3. กด ✕ ที่ชิปไฟล์ → ลบออกจากทุกเครื่อง (ต้องอยู่โหมดแก้ไข)
4. ข้อมูลพื้นฐาน `public/data/CUF*.js` ยังเป็นไฟล์ในโปรเจกต์ — เปลี่ยนแล้วต้อง deploy ใหม่ (หรือใช้วิธีอัปโหลด GeoJSON แทนเพื่ออัปเดตแบบสด)

## 6) ความปลอดภัย
- ตั้ง `EDIT_KEY` ยาว ๆ และใช้ **HTTPS** เสมอ (Render/Railway/Cloudflare ให้อยู่แล้ว) — รหัสถูกส่งใน header
- ไม่ตั้ง EDIT_KEY = ไม่มีใครอัปโหลด/ลบได้ (ปลอดภัยไว้ก่อน)
- ใครมีลิงก์ก็ **ดู** ได้ ถ้าข้อมูลภายในควรเพิ่มรหัสดูหน้าเว็บ (เช่น Basic Auth ที่ Caddy/Cloudflare Access)
- เซิร์ฟเวอร์ตรวจว่าเป็น FeatureCollection และจำกัดขนาด (`MAX_MB`)

## 7) ข้อควรรู้ / แก้ปัญหา
- **แผนที่ Google** (`mt1.google.com/vt`) เป็นลิงก์ไม่เป็นทางการ อาจผิดเงื่อนไขการใช้งานเมื่อเปิดสาธารณะ — ควรเปลี่ยนเป็น OpenStreetMap / Esri / Google Maps Platform (มี API key)
- ไฟล์ใหญ่มากโหลดช้า: บีบอัด/ลดจุดพิกัดก่อน หรือเพิ่ม `compression` middleware
- แถบขึ้น 🔴: เซิร์ฟเวอร์ปิด/หลับ หรือพร็อกซีตัด SSE (ดูข้อ Nginx)
- รันได้ **1 instance** เท่านั้น (รายชื่อผู้ออนไลน์และไฟล์เก็บในเครื่องเดียว) — เพียงพอสำหรับกลุ่มเพื่อนหลักสิบคน
- ไม่อยากดูแลเซิร์ฟเวอร์: ทางเลือกคือ Firebase Firestore/Supabase Realtime (ต้องเขียน live.js ใหม่ให้คุยกับบริการนั้น)
