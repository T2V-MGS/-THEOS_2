# Dashboard THEOS-2 (static site)
เปิด index.html ผ่านเว็บเซิร์ฟเวอร์ (ทดสอบ: python3 -m http.server 8000)
ไฟล์: index.html, data.js (ข้อมูล), img/ (โลโก้/favicon)
อัปโหลดทั้งโฟลเดอร์ไป Netlify Drop / GitHub Pages / Cloudflare Pages
หมายเหตุ: ใช้ Leaflet จาก CDN; ถ้าต้องการไม่พึ่ง CDN ให้ดาวน์โหลด leaflet.js/leaflet.css (v1.9.4) ไปไว้ใน lib/ แล้วแก้ลิงก์ใน index.html
